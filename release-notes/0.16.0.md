# Release notes for pkpdsim 0.16.0

pkpdsim 0.16.0 simulates with sbmlsim 0.15 ([sbmlsim 0.15.0](https://github.com/matthiaskoenig/sbmlsim/releases/tag/0.15.0)), builds the models of the PBPK library in about 40 % of the time of 0.15.0 and checks the units of a build in its flat model, where libsbml finds a wrong unit inside an organ. The SBML of a build is unchanged and the tests of pkpdsim pass unchanged on sbmlsim 0.15. What changes for a model comes with sbmlsim: an event which a change triggers and whose math has a function of SBML that PEtab names otherwise or lacks fires now, while a fit defined in python keeps the weighted least squares as its objective. It also makes tox use the interpreters of uv, so the tests run on python 3.15 of any Linux system, and a model release installs uv 0.13.6.

## Dependencies

- **sbmlsim** `>=0.15.0,<0.16` instead of `>=0.14.1,<0.15`. sbmlsim 0.15.0 adds the likelihood and the posterior as objectives of a fit (`FitSettings(objective=...)`) and reads PEtab v2 only.
- `uv.lock` moves to the newest releases: sbmlsim 0.15.0, sbmlutils 0.17.2 and tox 4.67.6, which fixes the staging of packages under umask 002 (tox-dev/tox#4357; `!=4.67.5` stays).

## Changes

- **Faster PBPK builds** ([#103](https://github.com/matthiaskoenig/pkpdsim/pull/103), [#104](https://github.com/matthiaskoenig/pkpdsim/pull/104)). A build of the toy definition takes 1.4 s instead of 3.5 s, the reference definition 2.3 s instead of 5.3 s. The comp and flat SBML of a build are byte-identical to 0.15.0 apart from the dates of the model history.
  - The comp model is read once (`pkpdsim.pbpk.builder.flat_model`), validated without the units, flattened in memory and the flat model is validated with strict units. libsbml checks the units of a comp document only in its top model, not in the model definitions of the organs, so a wrong unit of an organ parameter passed the check of 0.15.0 and fails the build now.
  - The flattening no longer lets libsbml's converter validate the comp model a second time (`performValidation` off, matthiaskoenig/sbmlutils#521).
  - The data files of the library are parsed once per process (`pkpdsim.pbpk.data.load` returns a copy).
- **Tests.** The tests share the flat models of a session across the pytest-xdist workers, by the hash of the comp model without its dates ([#104](https://github.com/matthiaskoenig/pkpdsim/pull/104)); continuous integration runs the tests of every platform in four shares, `--shard I/4` ([#103](https://github.com/matthiaskoenig/pkpdsim/pull/103)). The suite takes half the time of 0.15.0.

## Development

- **tox runs on the interpreters of uv** (`uv_python_preference = only-managed`) and its inline plugin `toxfile.py` puts the `libpython` of the interpreter of an environment on `LD_LIBRARY_PATH` ([#105](https://github.com/matthiaskoenig/pkpdsim/pull/105)). The wheel of libroadrunner 2.11.0 for python 3.15 needs the symbol `__jit_debug_register_code` of a `libpython` built with the experimental JIT, which e.g. the python 3.15 of deadsnakes lacks (sys-bio/roadrunner#1406); the installation guide describes it. The `ty` environment of tox runs on python 3.14. The tests of `--profile` expect the crash of the sampling profiler of python 3.15.2 as well, which writes a sample now and then with a `UnicodeEncodeError` (as 3.15.1).

## Model releases

- The model repositories which `pkpd_release` creates install **uv 0.13.6** instead of 0.13.4: the Docker image (`ghcr.io/astral-sh/uv:0.13.6`) and the `setup-uv` steps of the workflows ([#106](https://github.com/matthiaskoenig/pkpdsim/pull/106)).
