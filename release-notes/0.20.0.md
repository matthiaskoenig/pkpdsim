# Release notes for pkpdsim 0.20.0

pkpdsim 0.20.0 builds on sbmlsim 0.18: the generic parts of pkpdsim (the project of a model package, the records of its fits, the experiments over the draws of the adopted fits, the sensitivity runner, the credibility, the release of a model repository and the verification across versions) are part of sbmlsim, and pkpdsim keeps what is specific to PK/PD and PBPK models and adds it through the hooks of sbmlsim. The PBPK library describes the individual of a model (age, sex, species, circadian rhythms, pregnancy), the adipose tissue and obesity, and the impairment of liver, kidney and heart.

This is a hard break: the moved modules are not re-exported. The console scripts `run_simulation`, `run_fit`, `run_report`, `run_identifiability`, `run_credibility`, `pkpd_release` and `pkpdsim-verify` keep their names, options and defaults and run the kinds of `python -m sbmlsim.run`.

## Changes for a model package

- **The model is a project of sbmlsim** ([#143](https://github.com/matthiaskoenig/pkpdsim/pull/143)). `PKPDModel` subclasses `sbmlsim.project.Project`, the builds of the sexes are its variants (`model_path` is the default variant, `variant_path(variant)` any); the keywords of 0.19 (`fit_definitions`, `fits`, `model_path`, `female_model_path`, `data_paths`, ...) are still accepted.
- **Moved to sbmlsim** (import them from there): the licenses (`sbmlsim.licenses`), the distrib formulas (`sbmlsim.distrib`), the helpers of a scan (`sbmlsim.result.scan`) and of the units (`sbmlsim.units.define_unit`, `sbmlsim.data.rename_units`) ([#141](https://github.com/matthiaskoenig/pkpdsim/pull/141)); the filters, ids, starts and records of the fits (`sbmlsim.fit.filters`, `sbmlsim.fit.records`) ([#144](https://github.com/matthiaskoenig/pkpdsim/pull/144)); the experiments over the draws of the adopted fits (`sbmlsim.experiment.draws`) ([#147](https://github.com/matthiaskoenig/pkpdsim/pull/147)); the sensitivity runner and its parameter table (`sbmlsim.sensitivity.runner`, `sbmlsim.sensitivity.parameters`; `model=` is `project=`) ([#151](https://github.com/matthiaskoenig/pkpdsim/pull/151)); the credibility (`sbmlsim.credibility`) ([#152](https://github.com/matthiaskoenig/pkpdsim/pull/152)); the release (`sbmlsim.release`) and the COMBINE archive writer ([#153](https://github.com/matthiaskoenig/pkpdsim/pull/153)); the verification (`python -m sbmlsim.run verify`) ([#156](https://github.com/matthiaskoenig/pkpdsim/pull/156)).
- **The release settings** are `PKPDReleaseSettings` (`pkpdsim.model`), which carry the defaults of pkpdsim; a plain `ReleaseSettings` of sbmlsim is refused.

## Features

- **The console scripts run the kinds of sbmlsim** ([#150](https://github.com/matthiaskoenig/pkpdsim/pull/150)). A result is replaced only when its run succeeded, the inputs are never touched, a killed run leaves no staging behind, and every run records its spec, provenance and progress next to its result.
- **The credibility of a PBPK model on sbmlsim** ([#152](https://github.com/matthiaskoenig/pkpdsim/pull/152)). The ratio pairs, the temporal validation, the equivalency of the inputs and the study data are evidence extensions of sbmlsim, the PK checks (mass balance, zero dose, superposition, fates) a battery hook; the verdicts of the records of 0.19 are reproduced. The steady state is not checked for a model without a substance, as in 0.19.
- **The release of a model repository on sbmlsim** ([#153](https://github.com/matthiaskoenig/pkpdsim/pull/153)). `pkpd_release` builds a release with the kind `release` into `<repo>-release-<version>` next to the checkout (a build with `--pkpdsim-path` into `<repo>-release-<version>-local`, `--out` for another) and publishes it; the checkout is only read, a checkout with commits on `main` which the release repository does not have is refused. The PK-DB studies, ratios, temporal validation and inputs of the credibility page and the study names `<substance>/<study>` of the release notes are the ones of 0.19.
- **The individual of a model** ([#142](https://github.com/matthiaskoenig/pkpdsim/pull/142)): age, sex, species, circadian rhythms and pregnancy; the age tables read from the primary publications and the in vivo ontogeny of the hepatic CYP3A4 and CYP1A2 ([#155](https://github.com/matthiaskoenig/pkpdsim/pull/155)).
- **The adipose tissue, the body composition and the physiology of obesity** ([#148](https://github.com/matthiaskoenig/pkpdsim/pull/148)).
- **The impairment of liver, kidney and heart** ([#132](https://github.com/matthiaskoenig/pkpdsim/pull/132)): the studies of the parameter database, their consensus, MELD and the impairment classes.

## Differences users see

- The released repositories run `python -m sbmlsim.run ...`; the battery is headed "Battery of the variants".
- `pkpdsim-verify` refuses an abbreviated option and exits with 4 for a package without its model; an unexpected failure exits with 3.
- `--workers auto` is the number of CPUs of the quota of the container.

## Dependencies

- **sbmlsim 0.18** (`>=0.18.0,<0.19`).
- `sbmlode` is no longer a direct dependency (the archive writer of sbmlsim uses it).
