# Release notes for pkpdsim 0.24.0

The models of the PBPK library compile four to five times faster, every action of the workflows is pinned by the commit of its release, and the text of a definition can no longer leave the attribute or the script block of a figure. pkpdsim 0.24.0 runs on sbmlsim 0.22, whose least squares fits use every core.

## Features

- **The models of the library compile at `O0`** ([#187](https://github.com/matthiaskoenig/pkpdsim/pull/187)). A model of the PBPK library has large initial assignments, which `O0` compiles four to five times faster than `O2`, the default of sbmlsim: the reference models of the tests load in 7 to 11 s instead of 28 to 57 s, while they integrate at most a few percent slower. `DEFAULT_JIT_OPTIMIZATION` is resolved once, when the model is created, so that the experiments of a run, the problems of its fits, every worker of a pool, the tests and `pkpdsim-verify` agree on it; an explicit level is kept and `SBMLSIM_JIT_OPTIMIZATION` suppresses the default. `check_built` of the steady state takes the model from the cache of the library instead of compiling its own, so the check, the equilibration and the validity of the kidney outflow share one compile instead of three.
- **Every action of the workflows is pinned by the commit of its release** ([#187](https://github.com/matthiaskoenig/pkpdsim/pull/187)), with the version in the comment next to it: a tag and a branch move, and the release job of `ci-cd.yml` carries the identity of the trusted publisher of PyPI (`id-token: write`) and may create a release (`contents: write`), so a tag moved under it would hand both to whoever moved it. The eight pins were checked against the tags they name. `docs/development.md` states the policy and the comment of `dependabot.yml` says that the monthly updates move a pin and its comment together.

## Fixes

- **The text of a definition cannot leave the attribute of an SVG node or the `<script>` block of an interactive figure** ([#187](https://github.com/matthiaskoenig/pkpdsim/pull/187)). `escape` of the attribute values adds the double quote, and the cards of an interactive page go through `_script_json`, which escapes `<`, `>`, `&`, U+2028 and U+2029, since an HTML parser ends a script element at the first `</script` wherever it stands and a JavaScript string ends at a line separator, which JSON writes raw.
- **A `git` command cannot hang** ([#187](https://github.com/matthiaskoenig/pkpdsim/pull/187)). A lock of another process, or a repository on a file system which does not answer, let `git` run without a timeout; a folder now counts as no checkout after `GIT_TIMEOUT`, and `subprocess.SubprocessError` is caught beside `OSError`, so the timeout and a failure of the call give `None` alike.

## Differences users see

- The committed figures are written with the escapes above, so a figure of the repository changes in the escaped characters of its definitions and in nothing else.
- A model which names no level compiles at `O0` instead of `O2`, the default of sbmlsim, unless `SBMLSIM_JIT_OPTIMIZATION` names one, and the creation of a model writes the level into its settings. `O0` gives the results of the default JIT of roadrunner bitwise and the other levels differ from them in the last bits, by about the tolerance of the integrator, so the results of such a model move by that much (`pkpdsim-verify compare` shows it). A model whose fits integrate tens of thousands of times in one process, where the optimization pays for itself, names `SimulatorSettings(jit_optimization="O2")` itself.

## Internal

- ruff targets python 3.14 ([#187](https://github.com/matthiaskoenig/pkpdsim/pull/187)), the version of `project.requires-python`, instead of 3.13, so the pyupgrade rules and the formatter work against the syntax of the oldest interpreter the package supports: the quotes of 200 annotations (`UP037`, python 3.14 evaluates an annotation lazily, PEP 649) and the parentheses of an `except` of several types (PEP 758) are gone. `UnitDefinition` of `stationary.py` is a runtime import now, since the quotes of the field `unit` of `SteadyValue` were what let `typing.get_type_hints` resolve the class for `check_literals`.
- `import pkpdsim.pbpk` now pulls in `sbmlsim.engine` as well, with which `import sbmlsim` checks the installed libroadrunner since sbmlsim 0.22.0: it imports the standard library only, so the library still imports no roadrunner, COPASI or AMICI (`test_importing_the_library_imports_no_simulator`).
- CLAUDE.md drops what a session reads from `pyproject.toml`, `.ruff.toml`, `.github/` and `docs/development.md` and keeps the rationale, the gotchas and the pointers.

## Dependencies

- `sbmlsim>=0.22.0`, the latest release of sbmlsim, which pkpdsim is used with: a single least squares optimization now evaluates the points of its jacobian on the workers of the fit, so a fit of many parameters uses every core (a fit of 35 parameters of the machine perfusion model ran in 390 s instead of 6124 s on twelve cores), a profile of few parameters does the same, and `import sbmlsim` checks that the installed libroadrunner is a build of the `develop` branch, which the simulation of a model needs.
