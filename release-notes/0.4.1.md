# Release notes for pkpdsim 0.4.1

## Fixes

- pkpdsim requires `sbmlsim>=0.8.5,<0.9`. Why: 0.4.0 declared `sbmlsim>=0.8.5` without an upper bound, so a fresh installation resolved sbmlsim 0.9.0 (released 2026-10-11), which pkpdsim does not support: 0.9.0 removed the module `sbmlsim.simulator.simulation_serial`, which `pkpdsim.run` imports (`import pkpdsim.run` fails with `ModuleNotFoundError`), and the class attributes `fig_dpi` and `legend_fontsize` of `Figure`, which are fields of `FigureSettings` now. With sbmlsim 0.9.0 the tests of `tests/test_run.py` and `tests/test_verify.py` fail. Fixes: a fresh installation of pkpdsim resolves sbmlsim 0.8.x

## Notes

- A port to sbmlsim 0.9 follows in a later release, which lifts the cap.
