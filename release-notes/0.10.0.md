# Release notes for pkpdsim 0.10.0

pkpdsim 0.10.0 runs on sbmlsim 0.12 and requires python 3.14. It adds a profiler of the commands of the models, draws the figures of a model as SVG only by default and compares the values at the end of a scan relative to their scale in `pkpdsim-verify compare`. The release 0.9.8 of sbmlsim 0.11 ([#72](https://github.com/matthiaskoenig/pkpdsim/pull/72)) was not published; its changes are part of this release.

## Dependencies

- pkpdsim requires `sbmlsim>=0.12.0,<0.13` (was `>=0.10.0,<0.11`) and `sbmlutils>=0.17.0` (was `>=0.16.0`), and the lock of the development environment has sbmlsim 0.12.0, sbmlutils 0.17.0 and pydantic 2.14.1. sbmlsim 0.11 requires libroadrunner 2.11 and compiles a model with LLJIT, three to five times faster than before; sbmlsim 0.12 brings the acceptance criteria and the evaluation of a fit by subsets of its data, one figure per fit mapping, the uncertainty quantification (`sbmlsim.uncertainty`), the bands of scans whose simulations output the steps of the integrator and the datasets of an experiment in a folder `datasets` of its results ([release notes of 0.11.0](https://github.com/matthiaskoenig/sbmlsim/releases/tag/0.11.0), [of 0.12.0](https://github.com/matthiaskoenig/sbmlsim/releases/tag/0.12.0)).
- **The fits of data reported with a standard error change with sbmlsim 0.12:** every error of a fit is a standard deviation, a standard error is converted with the count of its data point (`SE * sqrt(count)`), which changes the weights of such data, and a data point with a standard error and without a count raises when the problem is initialized. The figure of a fit mapping is one figure of the curve, the goodness of fit and the Bland-Altman plot (`<experiment>_<mapping>`); the residual figures `fit_<experiment>_<mapping>` are no longer written.
- **pkpdsim requires python 3.14** ([#77](https://github.com/matthiaskoenig/pkpdsim/pull/77)). Python 3.13 is no longer supported, as by the rest of the pkdb modeling stack; the package is tested on python 3.14 and 3.15.

## Features

- **`--profile` runs a command under the sampling profiler of python 3.15** ([#76](https://github.com/matthiaskoenig/pkpdsim/pull/76)). `--profile` after the model package of `run_simulation`, `run_fit`, `run_report` or `run_identifiability` runs the command under the statistical sampling profiler of python 3.15 (`profiling.sampling`, PEP 799) and writes the profile into `profiling/<command>_<time>/` of the results of the model: the flame graph, the heatmap of the sampled lines, the statistics of the functions and the samples.

## Fixes

- **`collect_tsv_files` refuses a study of format 2 instead of copying nothing** ([#74](https://github.com/matthiaskoenig/pkpdsim/pull/74)). The study folders of format 2 of pkdb_data have no hidden TSV files, so the data of a model were left as they were without a message. `study_format` reads the format of a `study.json`, and `collect_tsv_files` raises a `ValueError` naming the studies of another format before it copies anything.
- **`pkpdsim-verify compare` compares a numeric array without a time relative to its scale.** The values at the end of the points of a scan, e.g. a clearance per renal function, have a dimension of the scan and no time. They were compared exactly, so a difference of 1e-11 between two versions of the simulator counted as an infinite difference. They are now compared like a timecourse, `max|new - old| / max|old|` on the same dimensions; an array of other dimensions is a difference, which the exact comparison did not see.

## Changes

- **The figures of a model are SVG only by default** ([#73](https://github.com/matthiaskoenig/pkpdsim/pull/73)). `FigureSettings` draws the figures of a model as SVG only (`formats=("svg",)`, was `("svg", "png")`), as the models of pkdb_models do. A run draws other formats on request (`--formats svg,png`); the PNG comparison of `pkpdsim-verify` needs runs with PNG.
