# Release notes for pkpdsim 0.7.0

pkpdsim 0.7.0 makes the vocabulary of the mapping metadata the same for all models.

The models of pkdb_models described the health of the subjects, the coadministered substances and the genotypes each with enums of their own. These are now shared vocabularies in `pkpdsim.metadata`, so the same metadata filters and tags the fit mappings of every model (pkdb_models#221).

## New features

### The shared vocabularies
`pkpdsim.metadata` has five new enums, the union of the vocabularies of the 43 models of pkdb_models with the synonyms merged:
- `Health` (36 members), e.g. `HEALTHY`, `RENAL_IMPAIRMENT`, `CIRRHOSIS`, `HEART_FAILURE`, `T2DM`, `NR`;
- `Coadministration` (123 members), the substances given together with the substance of the model, `NONE` for none;
- `Genotype` (55 members), the genotype of a group of subjects, every value with its gene (`CYP2C9 *1/*1`, `ABCB1 3435CC`, `SLCO1B1 and SLCO1B3 wild type`);
- `Phenotype` (8 members), the metabolizer phenotypes per enzyme (`CYP2C19 poor metabolizer`, `CYP2D6 ultrarapid metabolizer`);
- `AdministrationSite`, the site of an injection or an application (`ABDOMEN`, `THIGH`, `UPPER_ARM`).

`PKPDData` and `DataType` get the member `NR` (not reported). The members of every enum are documented in the module; the values are readable text and part of the API, a model may look up a member by its value.

### The fields of the metadata
`PKPDMappingMetaData` has the new fields:
- `health`, required;
- `coadministration`, `Coadministration.NONE` by default;
- `genotype`, `phenotype`, `administration_site`, `data` and `data_type`, not reported (`NR`) by default.

A model extends `PKPDMappingMetaData` only for a facet no other model has. The subclass lives in the mapping collections of the model, does not redefine a field of the base and adds no enum which repeats a vocabulary of pkpdsim.

### Filters without the metadata class
`metadata_filter` and `mapping_metadata` take `PKPDMappingMetaData` by default:

```python
# not executed
filter_control = metadata_filter(
    route={Route.PO, Route.IV},
    coadministration={Coadministration.NONE},
    excluded={"dosing": {Dosing.MULTIPLE}},
)
```

A model with a subclass passes it as the first argument, as before.

## Changes
- `health` is a required field of `PKPDMappingMetaData`: a metadata class which did not define it needs it now.
- A model which defined `Health`, `Coadministration`, `Genotype`, `Phenotype` or an injection site of its own imports them from `pkpdsim.metadata`. The members of a model may have another name or value in the shared vocabulary, e.g. a genotype without its gene (`*1/*1` is `CYP2C9 *1/*1`) or a metabolizer phenotype which a model described as a genotype.
- The tables of sbmlsim show the new fields for every mapping.

## Documentation
The page [Experiments](https://matthiaskoenig.github.io/pkpdsim/experiments/) describes the vocabularies, the fields and the rule for an extension of the metadata.
