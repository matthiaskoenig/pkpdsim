# Release notes for pkpdsim 0.1.0

First release of pkpdsim, the building blocks shared by the physiologically based pharmacokinetic and pharmacodynamic (PBPK/PD) models of [pkdb_models](https://github.com/matthiaskoenig/pkdb_models) ([pkdb_models#95](https://github.com/matthiaskoenig/pkdb_models/issues/95)). The modules are the shared modules of pkdb_models, moved unchanged so that the SBML the models create stays the same; with them the folder of a model imports nothing but itself and released packages.

## Modules

- `pkpdsim.templates`: `creators` and `terms_of_use` of a model (from `pkdb_models.models.templates`).
- `pkpdsim.annotations`: `compartments`, the annotations of the recurring compartments (from `pkdb_models.models.annotations`). The module imports `BQB` from `sbmlutils.metadata` instead of re-exporting the whole module with a star import.
- `pkpdsim.data`: `collect_tsv_files` (from `pkdb_models.models.data`) and the new `studies_dir()`, the study folders of PK-DB in a checkout of pkdb_data from the environment variable `PKDB_DATA`, else `../pkdb_data` relative to the working directory, with an error which names both when the folder does not exist.
- `pkpdsim.initial_values`: `init_concentrations_changes`, `init_amounts_changes` and `get_species_keys` (from `pkdb_models.models.pkpd`).
- `pkpdsim.licenses`: `License`, `license_text` and `write_license`, the texts of CC BY-SA 4.0 and MIT (with the copyright as an argument) for the COMBINE archive of a model. They reproduce the `cc-by-sa-4.0.txt` and `mit.txt` files of the models of pkdb_models byte for byte.

## Package

- Python 3.13 and 3.14 on Linux, macOS and Windows; the dependencies are sbmlutils and libroadrunner.
- Documentation with a user guide page per module and the API reference on [matthiaskoenig.github.io/pkpdsim](https://matthiaskoenig.github.io/pkpdsim); every python snippet of the documentation runs in the tests.
