# Release notes for pkpdsim 0.9.4

pkpdsim 0.9.4 lets the models pass the type check of ty 0.0.87.

## Fixes

- `PKPDSimulationExperiment` does not declare `Mr`, the molecular weights of the substances. ty 0.0.87 reports the narrowing of a declared class attribute as an invalid override of a mutable attribute (`invalid-mutable-override`), and the base of every model narrows the tuple of quantities of the base to its `NamedTuple`, whose fields its experiments read (`self.Mr.hctz`). The base does not use `Mr`; the base of a model declares it with its type, as before. A base which annotates the other conventions (`labels`, `units`, the maps of the impaired organ functions, `pk_labels`, `pk_units`) keeps the type of `PKPDSimulationExperiment`, `ClassVar[Mapping[...]]`, see the page Experiments of the documentation.
