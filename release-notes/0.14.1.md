# Release notes for pkpdsim 0.14.1

pkpdsim 0.14.1 is a security and dependency release of 0.14.0: it requires pillow 13.0.0, which fixes the advisories of pillow 12.3.0, and the releases of sbmlutils, pkpdutils and pkdb which allow it. The code of pkpdsim is the one of 0.14.0; the PBPK library on `develop` (#94) is not part of this release.

## Security

- **pillow** `>=13.0.0` instead of `>=12.3.0`: matplotlib writes its images with pillow, which reaches every user of pkpdsim, and pillow 13.0.0 fixes the 39 advisories of 12.3.0, among them the critical GHSA-5x8w-8jj5-q52h and the high GHSA-78g4-xqwv-q3g8, GHSA-g842-9rc4-69pw, GHSA-gg2r-wvfm-q9rx, GHSA-cp9v-662q-vvx9, GHSA-j4m9-6w36-pw47 and GHSA-p4wg-p73j-c528.
- The lock of the development environment, `uv.lock`, has **filelock** 4.2.6 instead of 4.1.0 (17 advisories fixed in 4.2.1, e.g. GHSA-2g95-wg33-c5x2) and **virtualenv** 21.15.2 instead of 21.14.6 (8 advisories fixed in 21.14.9, e.g. GHSA-394h-qwmc-48pf). Both are tools of the development only, so no floor is needed.

## Dependencies

- **pkdb** `>=0.12.19`, **pkpdutils** `>=1.4.0` and **sbmlutils** `>=0.17.1`, the releases with pillow 13 (pkdb 0.12.18 required `pillow<13`). pkpdutils 1.4.0 is stricter about the input of an analysis, see its release notes; the analyses of pkpdsim are unchanged.
- `uv.lock` moves every other package to its newest release, among them certifi 2026.10.23, numpy 2.5.4 and pandas 3.1.0 ([#96](https://github.com/matthiaskoenig/pkpdsim/pull/96)).
- **tox** `!=4.67.5`: tox 4.67.5 refuses its package staging directory when it was created under umask 002 (tox-dev/tox#4357), the lock keeps 4.67.4.
- **ruff** 0.17.3 and **ty** 0.0.95: the floors of the `dev` extra and the revisions of the pre-commit hooks are the locked versions again.
- The workflows and the setup action use astral-sh/setup-uv 10.3.3 ([#95](https://github.com/matthiaskoenig/pkpdsim/pull/95)).
