# Release notes for pkpdsim 0.35.0

The initial values of a substance are engine independent: `init_concentrations_changes` and `init_amounts_changes` take the model of a simulation experiment instead of a `roadrunner.RoadRunner`, so a model which the engine core, COPASI or AMICI simulates gets the same changes as a model of roadrunner.

## Changes

- **The initial values of a substance are engine independent** ([#251](https://github.com/matthiaskoenig/pkpdsim/pull/251)). `init_concentrations_changes(r, skey, value)` and `init_amounts_changes(r, skey, value)` read the species of a substance from the executable model of roadrunner (`getFloatingSpeciesIds() + getBoundarySpeciesIds()`), so they could only be called with a model which roadrunner had loaded. sbmlsim simulates with the engine core by default since its 0.37.0, which makes the model of an experiment an `sbmlsim.model.SBMLModel` of whatever engine its runner loaded, and the experiments of a model package had to re-implement the four lines of `_set_initial_values` to keep working. Both functions take that model now and read the species from its symbols (`ModelSymbols.species`, every species of the SBML, a boundary species included), which needs no loaded simulator at all: the changes of a model of the engine core are the ones of a model of roadrunner, of COPASI and of AMICI, and `pkpdsim.initial_values` imports no roadrunner any more. The keys are unchanged, the selections `[sid]` of a concentration and `sid` of an amount which every engine of sbmlsim reads, and the species are walked sorted, so the order of the keys of the returned mapping no longer depends on the order of the executable model.

  This is a breaking change of the signature of `init_concentrations_changes`, `init_amounts_changes` and `_set_initial_values`. A caller passes the model of its experiment where it passed `model.r` before:

  ```python
  changes = init_concentrations_changes(self._models["model"], "ldlc", concentration)
  ```

## Dependencies

- `sbmlsim>=0.36.0` is unchanged: `SBMLModel` and its symbols are older than that floor, so nothing of this release needs a newer sbmlsim. What it answers is the default engine of sbmlsim 0.37.0, which no longer hands an experiment a model of roadrunner.
