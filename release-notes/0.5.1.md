# Release notes for pkpdsim 0.5.1

pkpdsim 0.5.1 closes three small open points of the re-review of 0.5.0. It changes no behavior of a model which worked.

## Fixes

- `run_<model>` refuses an extra option named `--simulator`: the parser raises a `ValueError` naming the option when it is built. Why: `options.simulator` (the settings of the simulator of the run) is set after the arguments are parsed and silently replaced the value of an extra option of that name.
- The documentation of `pkpdsim-verify compare` names the second known false failure of the figure comparison across versions of sbmlsim, a size computed from a setting of the class `Figure` (`panel_width`) which the model changes, next to the one of a size set after the plots (`docs/models.md`). Why: only the release report knew it.
- `scripts/figures_sbmlsim_085.py` writes `tests/data/figures-sbmlsim-0.8.5.json`, the fixture of the figure comparison, with an environment of sbmlsim 0.8.5 and pkpdsim 0.4.1 (byte for byte the committed file); it is not part of the tests. Why: the fixture had no generator in the repository.
