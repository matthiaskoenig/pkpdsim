# Release notes for pkpdsim 0.9.6

pkpdsim 0.9.6 is a security release: the emSign root CAs have compromised intermediate keys, and pkpdsim and the model repositories it releases no longer trust them ([#67](https://github.com/matthiaskoenig/pkpdsim/pull/67)).

## Security

- pkpdsim requires `certifi>=2026.10.19`. certifi before 2026.10.19 trusts the emSign roots ([GHSA-6q48-6c7w-9gw2](https://github.com/advisories/GHSA-6q48-6c7w-9gw2)). pkpdsim does not import certifi; it is the CA bundle of requests, through which sbmlutils and pymetadata reach the network (identifiers.org and the ontologies of the annotations).
- The model repositories which `pkpd_release` creates install uv 0.13.4: the Docker image (`ghcr.io/astral-sh/uv:0.13.4`, was 0.13.1) and the `setup-uv` steps of the workflows `ci.yml` and `docs.yml` (`version: "0.13.4"`, the latest uv before), one version in `pkpdsim.release.project.UV_VERSION`. The CA store bundled with uv before 0.13.4 trusts the emSign roots ([GHSA-hq85-5cpj-mr62](https://github.com/advisories/GHSA-hq85-5cpj-mr62)).
- The lock of the development environment has certifi 2026.10.19 and uv 0.13.4.
