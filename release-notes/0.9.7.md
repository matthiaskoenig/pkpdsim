# Release notes for pkpdsim 0.9.7

pkpdsim 0.9.7 requires libroadrunner 2.11.0 ([#70](https://github.com/matthiaskoenig/pkpdsim/pull/70)).

## Dependencies

- pkpdsim requires `libroadrunner>=2.11.0` (was `>=2.10.0`), and the lock of the development environment has libroadrunner 2.11.0. libroadrunner 2.11.0 scales the absolute tolerance vector from the initial values of a model instead of the current values, so the parts of a timecourse which `pkpdsim.timecourse.run_simulation` runs one after the other are integrated with the tolerances of the initial state, not of the state at the start of a part. It also ends the last step of a variable step size run at the end time within the tolerance, updates the tolerances of the search for event triggers, fixes memory errors and ships wheels for python 3.12 to 3.15 ([release notes](https://github.com/sys-bio/roadrunner/releases/tag/v2.11.0)).
- The results of a simulation can differ from the results with libroadrunner 2.10.0 within the tolerances of the integrator; `pkpdsim-verify compare` shows these differences for the experiments of a model.
