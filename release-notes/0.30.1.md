# Release notes for pkpdsim 0.30.1

The build cache of 0.30.0 is the cache of the user and no output of a model.

## Fixes

- **The build cache lives in the cache folder of the user** and not beside the models it builds. 0.30.0 kept the validated pair of a build in `output_dir/.pkpdsim-cache/<model>.zip`, inside the directory of the models, which a model package tracks and compares against a rebuild (`Project.changed_outputs` of sbmlsim): the archive is not reproducible, so every such comparison failed with a difference of the cache and no difference of a model, and a release export, which refuses an ignored file, saw a file its `.gitignore` had hidden. The cache is now `pkpdsim/build` of `XDG_CACHE_HOME` or of `~/.cache`, as sbmlsim keeps its own caches, with one entry per key as a shared directory has (`cache_root`, `cache_path(key)`), so a build writes nothing into the model directory and the cache is still reused without configuration. `PKPDSIM_BUILD_CACHE` keeps its meaning, a directory to share the validated builds or `off` to validate every build, and an entry of 0.30.0 beside the models is not read any more and can be removed.
