# Release notes for pkpdsim 0.30.0

An inhaled dose is a route of the PBPK library, and a model which was already composed and validated is reused instead of built again. With sbmlsim 0.30.0, whose scan assembles its result with one copy instead of four, whose fit on the engine core evaluates a whole jacobian as one batch of that engine and whose engine core simulates algebraic rules and delays, and pkpdutils 1.7.0, whose kernel links no mimalloc on macOS and draws the uncertainty of a group curve in rust.

## Features

- **The inhaled route of the PBPK library** ([#204](https://github.com/matthiaskoenig/pkpdsim/pull/204)). `Route.inhaled(s, ka=..., deposited=..., swallowed=...)`, next to the oral, the intravenous and the solution route. An inhaled dose is split in three: the deposited fraction reaches the lung and is absorbed into it from a depot with a first order rate (`INHDOSE_<s>`, `Ainh_<s>`, `ka_inh_<s>`, into `LU__Cpl_<s>`, or `LU__Cor_<s>` where the organ has no plasma), the swallowed fraction is added to the oral dose state of the gut lumen (`R_inh_swallow_<s>` in the rate rule of `PODOSE_<s>`, the one place which owns it), and the rest is a loss accounted for in a sink (`Aloss_inh_<s>`), so the dose of a simulation is conserved and the mass balance check of the credibility battery holds. The defaults of the parameter table are `f_inh_deposited_<s>` 0.2, `f_inh_swallowed_<s>` 0.8 and `ka_inh_<s>` 1/hr, every one a model choice: a route which states one fraction gets the rest of the dose as the other, as a formula over the one it states, so the pair stays exact wherever the initial assignments are evaluated again (a fitted value, the pre-initialization of a scan, a draw of the uncertainty); a pair whose sum is above the dose and a stated fraction outside 0 to 1 are refused when the definition is validated, since the loss would be negative and the body would receive more than the dose while the arithmetic stayed conserved; a pair where either fraction is a formula is not checked, which `Route.inhaled`, `Depot.swallowed` and `inhaled_split` say; and a route without an oral route to swallow into is refused. The ids, the annotations (`NCIT:C38216`, `UBERON:0002048`), the figure of the model and the web app know the new dose state.

## Fixes

- Protect model input data and unfamiliar nonempty directories from CLI output replacement. Concurrent writers use a per-result lock, interrupted publication restores the previous result, and failed simulation retries retain the earlier report.
- Keep the model clock and delayed events continuous across segmented timecourses, and reset initial event delays before repeating a simulation.
- Align uncertainty draws by time, preserve discontinuities, skip failed draws, and return an empty band when every draw fails.
- Treat a study's collection date as unknown when a candidate data copy lacks provenance, so temporal validation cannot claim that evidence was collected after fitting.

## Performance

- Reuse checksum-verified, validated PBPK model pairs when the composed SBML, software versions, and validation settings match. Unchanged outputs retain their modification times. Set `PKPDSIM_BUILD_CACHE` to a shared directory or to `off`; models with external references always revalidate.
- Read kidney validation values from the initialized model instead of integrating a one-minute simulation for each condition. Keep recent values in a bounded cache.

## Changes

- **sbmlsim 0.30.0**, the floor and the lock, with sbmlsim-core 0.11.0: a scan assembles its result with one copy instead of four and writes the points of a wide chunk on threads, a fit on the engine core evaluates the whole jacobian of a step, or the whole population of a generation, as one batch of the engine instead of one point per worker process (2.1 to 3.4 times the loop over its vectors on the PK fit of the HCTZ example), and the engine core simulates a model with algebraic rules with SUNDIALS IDA and one with the `delay` csymbol with an integrator of its own for them, so it refuses neither any more.
- **libroadrunner 2.12.0.dev683**, the floor and the lock, which is the floor of sbmlsim 0.30.0: sbmlsim compares the installed libroadrunner with its own requirement at `import sbmlsim` and raises an `ImportError` for an older build, so a lower floor here would let an install resolve to a build sbmlsim refuses. The installation page and the README name the new build in the command which installs it from the index of the builds of the `develop` branch.
- **pkpdutils 1.7.0**, the floor and the lock, with pkpdutils-core 0.6.0, whose macOS wheel links no mimalloc. Two extension modules which each statically link mimalloc claim the same two slots of the pthread TLS block on macOS, by compiled-in number, so each reads the heap of a thread the other left there and frees blocks through a page map which never saw their arena. An environment which loads both pkpdutils and a model package built on sbmlsim-core therefore corrupted its heap on macOS ([pkpdutils-core#11](https://github.com/matthiaskoenig/pkpdutils-core/pull/11)). 1.7.0 moves the parametric bootstrap and the delta method of a group curve into the kernel, whose counter-based generator draws the replicates of a seed alike in python and in the browser; the bootstrap columns of a group curve therefore move by the Monte Carlo error of their replicates, while the point estimates, the delta method and `summarize` are unchanged. No analysis of pkpdsim reads them: it reads the non-compartmental analysis of `pkpdsim.pk` and its point estimates.
- The fixes and the performance of this release were listed in `release-notes/unreleased.md`, which is folded into these notes; this repository keeps one file per version, which the release workflow reads for the body of the GitHub release.
