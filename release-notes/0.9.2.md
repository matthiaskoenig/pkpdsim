# Release notes for pkpdsim 0.9.2

pkpdsim 0.9.2 fixes the CI workflow which `pkpd_release` writes into a model repository, found in the first CI run of hctz-model 0.9.0 ([#54](https://github.com/matthiaskoenig/pkpdsim/pull/54)).

## Fixes

- The CI workflow of a release puts `libpython` on the library search path before the dependencies are installed. The extension of libroadrunner links against `libpython`, which the standalone interpreters of uv ship in their `lib` directory, where the loader on Linux does not look, so the first CI run of hctz-model 0.9.0 failed at `run_simulation` with `libpython3.14.so.1.0: cannot open shared object file`. The step exports `LD_LIBRARY_PATH` as the setup actions of pkpdsim and pkdb_models do. A model repository gets the step with its next release.
