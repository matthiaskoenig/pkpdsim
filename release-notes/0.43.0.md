# Release notes for pkpdsim 0.43.0

pkpdsim moves onto sbmlsim 0.48.0: a fit whose simulation group is a scan is a fit of the engine, the pool of a run of experiments starts before the experiments are initialized, a model reads its SBML once and the engine core simulates a small scan on every CPU.

## Changes

- **sbmlsim 0.48.0** (the floor is `sbmlsim>=0.48.0`): scan groups in the engine (sbmlsim#624), the pool of a run first, an SBML read once and the threads of the engine core for a small scan; the browser examples (cardiovascular, lobes) are exported again from it.
- **`run_pipeline --list`** names a step of one core in the singular, `1 core` (#270).
