# Release notes for pkpdsim 0.27.0

The interactive figure of a model has a second form, the snippet: one `<div>` with the figure, its hover cards and its script, which a page of markdown or HTML embeds as it is. The factory writes the snippet of each figure beside its SVG, and the documentation of a released model repository embeds them on its index (sbmlsim 0.26.0), so a reader of the index hovers the organs, substances and processes of the model instead of looking at a static image.

## Features

- **The interactive figure of a model as a snippet** ([#195](https://github.com/matthiaskoenig/pkpdsim/pull/195)). `interactive_figure(definition, path, figure=..., snippet=True)` of the PBPK library and `interactive_circuit(definition, path, figure=..., snippet=True)` of the machine perfusion library write the snippet of a figure (`html_snippet`) instead of a whole page: everything of it is scoped to its `<div>` (`pkf-<sid>-<figure>`), the style sheet of the snippet, the style sheet and the ids of its SVG and the script, which is a closure over it, so the two snippets of a model stand on one page without touching the page or each other. The snippet carries its own light background, so it reads in a dark theme as well, and it has no blank line, which would end it in a page of markdown; a style sheet with an at-rule or a comment, which cannot be scoped, is refused.
- **The factory writes the snippets beside the figures** ([#195](https://github.com/matthiaskoenig/pkpdsim/pull/195)). `create_archive(..., figure=True)` of `pkpdsim.pbpk` writes `<sid>.html` and `<sid>_body.html` and `create_archive` of `pkpdsim.perfusion` writes `<sid>.html` and `<sid>_anatomy.html` beside the SVG figures. They are no entry of the COMBINE archive, which carries the figures as SVG. `interactive_figure` takes the `sexes` of the archive as well, so the interactive figure names the builds as the static figure does. `html_page` is unchanged, so the frames of the pkpdsim documentation stay as they are.

## Dependencies

- `sbmlsim>=0.25.0` ([#194](https://github.com/matthiaskoenig/pkpdsim/pull/194)), which exports the panels and the app of a model as a static bundle a page runs without a server, and integrates a panel to its output times.
