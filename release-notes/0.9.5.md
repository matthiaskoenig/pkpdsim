# Release notes for pkpdsim 0.9.5

pkpdsim 0.9.5 adds two helpers which the models of pkdb_models share instead of their own diverging copies.

## Features

- `pkpdsim.timecourse`: the timecourse of a roadrunner model which is simulated in parts (`SimPart`, `Simulation`, `run_simulation`), for the tissue and perfusion models which run their models directly with roadrunner. A part sets its changes at its start and runs from the state of the part before; `run_simulation` resets the model, runs the parts and returns one timecourse whose time continues over the parts. The steps of a part have no default ([pkdb_models#118](https://github.com/matthiaskoenig/pkdb_models/issues/118), #64). See the page Timecourses in parts of the documentation.
- `PKPDSimulationExperiment.add_doses(times, doses)`: repeated doses which add to their dose states (`"PODOSE_x + <dose>"`, the dose in the unit of the state in the loaded model). A change of the dose state to the dose discards the rest of the earlier doses which is not yet dissolved, absorbed or infused ([pkdb_models#105](https://github.com/matthiaskoenig/pkdb_models/issues/105), #65). See the section Repeated doses of the page Experiments.
