A native build which links `sbmlsim-csolvers` (the native engine, its tests) contains the libraries as well.

KLU and BTF are under the GNU Lesser General Public License 2.1 or later and are linked statically into `engine.wasm`. Their complete source is in the submodule at the commit above, and the complete source of `engine.wasm` and its build are in this repository (`cargo build`, see the README: the build script of `sbmlsim-host`, or `SBMLSIM_CORE_WASM_DIR` for an `engine.wasm` built otherwise), so a recipient can modify KLU or BTF, build `engine.wasm` again and use it with the hosts in place of the distributed one.

Also compiled into the modules, under permissive licenses whose texts are in their sources: the Rust standard library (MIT OR Apache-2.0); in `engine.wasm` the crates serde, serde_json, itoa, rand_core, rand_pcg and thiserror (MIT OR Apache-2.0), memchr (Unlicense OR MIT) and zmij (MIT), and wasi-libc, which the Rust target wasm32-wasip1 links (Apache-2.0 WITH LLVM-exception OR Apache-2.0 OR MIT, with parts of musl under MIT; the C of the solvers is compiled against the sysroot of wasi-sdk 34); in `mathlib.wasm` the crate libm (MIT). `model.wasm` contains no third-party code.

`mathlib.wasm` and the crate `sbmlsim-mathlib` it is built from (which every native build of the compiler links for constant folding) also contain `exp`, `log` and `pow` of ARM optimized-routines (https://github.com/ARM-software/optimized-routines, commit 20859d3fd9e797dde592c489c8ef7d383f778620: `math/exp.c`, `math/log.c`, `math/pow.c` and their tables), ported to Rust in `crates/mathlib/src/arm`. optimized-routines is under `MIT OR Apache-2.0 WITH LLVM-exception` and is used here under the MIT License, whose text is below.

The extension module of the python package (`sbmlsim_core._core`, the crate `sbmlsim-python`) additionally links mimalloc 3.3.2 statically on every target but macOS, where it allocates through the system allocator and the wheel links none, because two extension modules which each link a copy of mimalloc claim the same two fixed slots of the pthread TLS block there (the allocator of the extension, `crates/python/src/lib.rs`, where the long version is; `sbmlsim_core.__allocator__` reports which of the two a build is). Its C sources are vendored in the crate `libmimalloc-sys` 0.1.49, which compiles them with `cc`; mimalloc is under the MIT License (Microsoft Corporation, Daan Leijen) and the crate which wraps it under the MIT License (Octavian Oncescu), both texts below, which the wheels carry whether or not their platform links it. Nothing else carries mimalloc: it is in no wasm module, in no other crate, in no package of the JavaScript host and in no wheel for macOS.

The native Wasmtime hosts (`sbmlsim-host`, the command line and the Python extension) also link Zstandard 1.5.7 for the persistent compilation cache, through `zstd` 0.13.5, `zstd-safe` 7.4.1 and `zstd-sys` 2.1.3. Zstandard and these Rust wrappers are used under BSD-3-Clause; their license texts are below. These cache dependencies are in no Wasm module and in no package of the JavaScript host.
