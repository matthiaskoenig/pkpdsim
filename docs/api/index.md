# API reference

The API reference is generated from the docstrings of the package.

Some building blocks of the models are part of sbmlsim and are documented in its [API reference](https://matthiaskoenig.github.io/sbmlsim/api/): the texts of the licenses of a model ([`sbmlsim.licenses`](https://matthiaskoenig.github.io/sbmlsim/api/licenses/)), the distrib formulas of the draws of a fitted parameter ([`sbmlsim.distrib`](https://matthiaskoenig.github.io/sbmlsim/api/distrib/)), the dimensions, the timecourse, the band and the start and end values of a point of a scan ([`sbmlsim.result.scan`](https://matthiaskoenig.github.io/sbmlsim/api/result.scan/)), the SId of a text ([`sbmlsim.experiment.to_sid`](https://matthiaskoenig.github.io/sbmlsim/api/experiment.sids/)), the definition of a unit ([`sbmlsim.units.define_unit`](https://matthiaskoenig.github.io/sbmlsim/api/units/)), the renaming of the units of a table ([`sbmlsim.data.rename_units`](https://matthiaskoenig.github.io/sbmlsim/api/data/)), the run of the experiments of a model ([`sbmlsim.project.Project.run_experiments`](https://matthiaskoenig.github.io/sbmlsim/api/project/)) and the run of the experiments over the draws of the fitted parameters ([`sbmlsim.experiment.draws`](https://matthiaskoenig.github.io/sbmlsim/api/experiment.draws/)).
