# release

The release of a model repository, see [Release of a model repository](../release.md). The release is sbmlsim's (`sbmlsim.release`), a model package uses its release settings (`sbmlsim.release.settings`); pkpdsim adds its release hook and the command `pkpd_release`, whose function is `main`, `release` is the release as a function.
