# pbpk regional absorption

The derivation of a regional absorption profile with the model from a release study: `release_auc_ratios` (the AUC of a solution released in a segment relative to the oral solution), `derive_regional_absorption` (the factors of a `RegionalAbsorption` which give the reported ratios) and `regional_key`, see [Intestine and routes](../pbpk/intestine.md#regional-absorption).
