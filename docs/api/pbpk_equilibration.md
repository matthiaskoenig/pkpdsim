# pbpk equilibration

The drug-free equilibration of a condition: `equilibrated_simulation` outside an experiment (the groups of a sensitivity analysis), which `PBPKSimulationExperiment.equilibrated` shares, `drug_free_zeros` (the species of the drugs which start exactly at 0), `accumulating_states` and `growing_states`, see [Impairment](../pbpk/impairment.md#equilibration-of-a-condition). The names are importable from `pkpdsim.pbpk.experiment` as well.
