# pbpk experiment

The base of the simulation experiments of a model built on the PBPK library: the healthy GFR of an individual, the validity of the kidney outflow of an individual, the renal function of a measured clearance and the maps of the classes of a study onto the severities of the library, see [Impairment](../pbpk/impairment.md#classes-in-experiments).
